Problem 
•	The problem to be solved is creating a program to choose from 3 sets of conversions and to convert a number above 0 and less than 1000 to a different unit of measurement.
•	Some of the unique aspects of this project include asking the user for an inputted number, a set of conversion units, input validation, and using a calculator to test the calculations accuracy.
Analysis
•	I decided to solve the problem by asking for a number initially and then making a numbered menu to select from volume, length, and weight. The user must then select an initial unit of measurement to convert to all units in the same set to be output at the end.
•	The most difficult part of the project was getting the correct output and making sure the program runs again at the end of the calculations.
•	I approached this project in multiple different ways including the output portion, the functions portion, and trying it every way possible. I finally decided the final project was the best way to calculate and output and run again if necessary. 
Design
•	I designed multiple functions to be called and also make the program do calculations a second time if needed.
•	I did not include or create any libraries, modules, or tools like the instructions asked for, but I did create multiple functions that are commented in the project though.
Testing
•	I tested the project by running it many times to make sure the function calls were working correctly. I also tested the calculations with a calculator multiple times and with different numbers and decimals to ensure its accuracy.
•	I tested a wide variety of inputs, numbers, and decimals to make sure nothing threw the program out of whack when testing.
•	The program did not throw any exceptions after adding input validation and ensuring it was working correctly during testing.
Reflection
